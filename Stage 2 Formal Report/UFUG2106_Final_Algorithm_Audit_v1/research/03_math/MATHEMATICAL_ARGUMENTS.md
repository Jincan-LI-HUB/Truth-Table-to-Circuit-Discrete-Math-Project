# From truth to the billable network

**Objects and units.** The input fixes a vector function F on n bits (line 3, x0 most significant). A candidate G is a topologically numbered gate DAG with m output references. A procedure π constructs G under wall time and RSS constraints. Two procedures emitting the same bytes have equal circuit costs on the same instance even when their running times differ. A valid emitted wire can still fail a resource cap. The course handout counts every *listed* gate. Live area equals that count after compaction, as in Builder::finish. A listed disconnected NOT 0 is a direct counterexample to using reachability as the evaluator definition. D is the maximum output arrival, independent of the number of gates on other parallel paths.

**Proposition 1 (representation).** For a variable x and restrictions f0 and f1, f=(¬x ∧ f0) ∨ (x ∧ f1). Substitution of either value proves equality row by row, and induction over the variable order gives an exact vector representation when applied to each output. For one fixed total order and fixed terminal/phase conventions, the ordinary reduced ordered diagram is unique up to isomorphism. Induct on the remaining support: the root of a nonconstant function must test its first essential variable, since earlier equal-cofactor nodes disappear; the children are the unique representations of the restrictions and a unique table merges identical triples. Complement pointers can represent a function and its negation using one regular node when the stored phase is normalized. They do not implement a free gate-level inverter. For the selector x?y:z, a selector-first order has three ordinary nonterminals (x, y, z); a data-first order y,z,x has five (y, two z tests, x and ¬x). Its primitive unsimplified MUX still needs one NOT, two ANDs and an OR. Constants, orientation, existing negations and shared gates change this bill. The number of distinct restricted functions can grow exponentially. Portfolio search controls the order and leaf realization, without proving a smallest mapped DAG. Historical R1 passed 25 but met only 12 deadlines. Zeyun's no-order control kept 25 deadlines but increased area; ordering is neither necessary for feasibility on every bank nor sufficient to optimize area.

**Proposition 2 (marginal area).** Let L and L' be gate sets reachable from all outputs before/after replacement, using persistent identities and fixed gate types and weights. In A(G')−A(G) the intersection cancels, leaving ∑(L'∖L) a(v) − ∑(L∖L') a(v). This is exact because gates are charged once. A cut frontier need not delimit which old gates become dead. With renumbering one must first establish a correspondence of unchanged nodes, or use two independent weighted counts. Type counts by difference remain exact even without identities. Builder interning uses (op, canonical fanins) and deduplicates equal syntax, without merging all equivalent functions.

**Worked network.** Take p=ab, q=ac, r=p∨q, s=¬r. Expose (p,q,r,s). Costs (area,delay) are AND (2,1), OR (3,2), NOT (1,1). Original charges 2+2+3+1=8. Reexpress r=a(b∨c). Seen in isolation its cone falls from 7 to 5. Both old products remain outputs; the new list contains p,q,b∨c,r',¬r', costing 2+2+3+2+1=10. Cancelling p,q and the equal *cost* of the changed inverter leaves +2. When only r and its complement are exposed, the same change costs 6 instead of 8. In both examples the functions are preserved. Thus the external observation boundary can reverse the sign of a locally identical change. Code-level tests execute the four-output example and full cut masks.

**Proposition 3 (cut substitution).** Assume every path from a primary signal to a root hits the frontier (constants may be evaluated directly), each frontier signal has the same meaning before/after, and new nodes depend only on these signals, constants and earlier new nodes. Equality on all 2^k independent frontier assignments implies equality on the subset of reachable assignments. For each primary input assignment substitute the actual leaf tuple; induction in topological order preserves all descendants and outputs. Reachability restrictions mean full-mask equality is sufficient and need not be necessary. Reusing a descendant of the removed root invalidates the acyclicity premise. Truth-mask bit j uses the local order of leaves, distinct from the input file ordering. In the example with a the low bit, set bits 3,5,7 give 168. SOP cubes must contain no zeros and cover every one; Shannon splits must cover both restrictions. The production cut path constructs these expressions by identity, while the signature-indexed library is a separate opt-in. The new test instantiates each three-input mask with two SOP policies and a Shannon order using frozen headers and checks the resulting graph. This exercise does not exhaust four-leaf search, runtime paths or whole-program correctness.

**Proposition 4 (timing at a fixed boundary).** Let τ(v)=0 on primary signals, τ(v)=d(v)+max τ(u) over fanins otherwise. Every path ends with one incoming edge, proving the recurrence by topological induction. Initialize each output reference with deadline Δ (all others +∞). For each node u in reverse order, R(u) is the minimum of its output deadline if applicable and all R(v)−d(v) over its immediate users. Unrolling enumerates the tightest residual deadline over downstream paths. Slack equals R−τ. In the example Δ=4, arrivals of (p,q,r,s) are (1,1,3,4). Although r directly drives an output, its inverted output tightens R(r) to min(4,4−1)=3. R(p)=R(q)=1; the factored replacement still arrives at 3. A delay-4 equivalent driver would pass the direct output check and miss the inverter's deadline. Within the specified circuit insert a double inversion after r, yielding arrival 5 and s at 6. The abstract delay-4 boundary and concrete delay-5 counterexample illustrate different violations. If only one driver changes and all downstream topology, fanin arrivals elsewhere and edge delays remain fixed, τ'(r)≤R(r) suffices in a previously feasible network. Multiple boundary drivers respecting all their old requirements likewise suffice for fixed downstream logic. Across a remap, fanout and shared nodes may change. Rebuild and rescore all outputs. A lower global area and delay ≤ Δ permit a longer path than the incumbent. The strict postpass predicate concerns one invocation's incumbent, not the result of another timed run.

**Composition and measurement.** A rewrite is a map on circuits, not just on truth functions. Cofactor synthesis, exact cuts and structural rehashing preserve F; operation A can create the shared term that operation B would otherwise be unable to reuse. Nonadditivity is measurable only against a fixed starting graph and acceptance rule. In R4 the same original case nets were postprocessed with phase, algebra, phase→algebra and algebra→phase. One-run aggregate standalone savings sum to 1,616 versus 1,627 or 1,625 in the two orders. Those totals hide opposite case-level interactions (see order_effects.csv). They describe these operators on the archived incumbents. In R8 adding iterations also changes work and the candidate windows. Comparing a single pattern pass to several is not a factorial test of pure order.

**Budgeted acceptance.** Let H_i=1[A_candidate<A_base] on jointly valid pairs, S_i=A_base−A_candidate, U_i=T_candidate/T_base. Describe coverage, ∑H_i, ∑S_i, ∑max(S_i,0), worst case and exp(mean log U_i) separately. Never give failed cases a fabricated area or runtime. With fixed incumbent and nested candidate set the minimum feasible area cannot rise as candidates are added; wall-time truncated program traces need not be nested. The production extra pass runs only for a valid feasible incumbent, limit≥1000 and allowance min(90,0.06·limit,0.82·limit−elapsed)≥8 ms. It ranks at most 160 default repeat roots, rebuilds with a fallback for untouched nodes, and accepts only a valid, strictly smaller whole graph meeting the deadline. Cooperative time polls do not bound process shutdown. R10.1's nominal 45-ms control lost area and had a geometric elapsed-time ratio above one. R8.6 separates quota from reclaim on two frozen banks; only those interventions support factor-specific claims. Rows, contrasts and caveats are in the analysis directory.
