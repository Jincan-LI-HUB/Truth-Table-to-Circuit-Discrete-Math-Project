# Figure provenance: exact scripts, data, and output paths

Each figure has `PDF` (vector) and `PNG` (raster) versions in `shared/figures/`; both are generated by **`shared/scripts/make_figures.py`** with **`shared/palette.json`**. No charts were redrawn with manually entered numbers.

| Figure | Input CSV | Relevant raw source | Key limitation |
|---|---|---|---|
| `area_evolution` | `round_history.csv` | 9 archived WSL official CSVs from Round1–6.1 | Different historical rounds are not jointly controlled; do not infer speedups |
| `paired_runtime` | `paired_benchmarks.csv` | 7 actual same-run paired comparisons (R4.1→5, R5→5.1 twice, R5.1→6.0 twice, R5.1→6.1 twice) | Bars show within-comparison mean of run medians; no confidence intervals |
| `cut_case_savings` | `stage1_per_case.csv` | Round 5.1 run 1 and Round 6.1 run 1 official CSVs | Different run sessions, descriptive case-by-case area only |
| `holdout_area` | `cut_holdout.csv` | Fresh Round6.1 40-case and 8-case holdout official CSV pairs | Synthetic families are not hidden Stage 2 distribution |

| `round3_ablation_path` | `round3_ablation_path.csv` | user-uploaded `ablation_summary(1).csv` | Sequential development path, *not* isolated module effects; excludes the separate implication branch |
| `round4_postprocess_ablation` | `round4_postprocess_aggregate.csv` | `Round4_postprocess_comparison.csv` (25 per-case rows) | Postprocessing only; full Round 4 later searched extra variable orders; best per case is a selector |
| `round61_budget_tradeoff` | `round61_budget_development.csv` (large subset) | user-uploaded 16-case development budget JSON | Local Cut search result and local wall time, *not* official Stage 1 aggregate or full synthesizer runtime |

Non-plotted evidence: `peak_rss_single_case.csv` comes from the student-provided `case_024` terminal excerpt; `stage1_round51_research_freeze_manifest.json` verifies research-source SHA-256. Original raw ablation CSVs and JSONs are preserved under `shared/data/raw_evidence/` with checksums.

To recreate:

```bash
python shared/scripts/make_figures.py
```

Optional original-archive extraction:

```bash
python shared/scripts/extract_evidence.py --source-dir '/your/local/ZIP/directory'
```

**Palette**: user-supplied `#FAD6C9 #B0C6A8 #FAF5E8 #92B3CD #D99DA3 #D0E3DB #A6B3C0 #E8E2DB`, stored in `palette.json` and LaTeX `palette.tex`.

## Editable conceptual figures (not empirical measurements)

- **Figure 1**: `technical_report/figures/research_overview.tex` (TikZ). This is a schematic of the frozen Round 5.1 algorithm and the later Round 6 branch; it contains one verified area-sum metric copied from the official Round 5.1 record, not invented sample data.
- **Figure 2**: an inline TikZ drawing in `technical_report/main.tex`, linked to the three-input/two-output worked example and `shared/scripts/verify_worked_example.py`. Arrows depict **functional cofactor use**, not physical gate edges.
- **Table I**: `shared/scripts/make_milestone_table.py` transforms `shared/data/round_history.csv` into `shared/data/milestones_with_runtime.tex`, including a representative median runtime per round with explicit comparability warning.
- **Test-suite generation**: sources and case-hash manifests in `shared/test_generation/`; explanatory protocol in `shared/evidence/TEST_SUITE_PROTOCOL.md`. These scripts are stored separately from the official Stage 1 assets.
